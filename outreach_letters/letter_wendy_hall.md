I built an alternative.

I am a software developer with years of experience, an independent inventor, and the author of 17 books on breakthroughs in science and technology. I built an open-source distributed AI system that runs entirely on local hardware, on a local network, with zero external data transmission. No American servers. No Big Tech involvement. No data leaving the building.

How it works: a stronger local AI model acts as a coordinator. It takes a task, breaks it into independent sub-tasks, and distributes each to a separate machine on the local network. Each machine runs its own complete AI model and processes its sub-task independently. Zero communication between machines. When done, the coordinator combines the results. Everything runs behind a firewall on computers the organisation already owns.

This is not a product. This is not a startup. It is free, open-source, and it works. Every line of code is visible on GitHub. A British university, a British hospital, a British government department can run world-class AI on its own computers without a single byte touching an American server.
