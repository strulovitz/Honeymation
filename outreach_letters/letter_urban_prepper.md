As an engineer, here is what will interest you about the architecture: a stronger local LLM acts as a coordinator. Each machine runs its own complete LLM instance and processes its sub-task with zero inter-node communication. No shared memory. No message passing. Pure task-level parallelism with complete worker independence. When all workers complete, the coordinator aggregates results. The entire pipeline runs on commodity hardware behind a firewall. It works on Ollama with any open-weight model. No binary blobs, no license servers, no cloud callbacks.
