I built an open-source distributed multi-agent AI system where a coordinator agent — a stronger local LLM — receives a task, decomposes it into fully independent sub-tasks, and distributes each sub-task to separate worker agents running on separate machines on a local network. The entire system runs behind a firewall. Nothing leaves the network. Everything is local, inspectable, and under the operator's control.
